# 品牌图片放这里

logo.svg：网站 Header Logo。
app-icon.svg：App 图标。
favicon.svg：浏览器图标，可替换为 .ico/.png。
hero-app.svg：首页手机主视觉，建议保持 1200:2664 的纵横比。
social-preview.svg：分享卡片，正式使用建议替换为 1200×630 PNG/JPG。

修改文件名时同步更新根目录 site.config.json 的 assets。资源引用路径以 /brand/ 开头，不含 public。
所有现有图片均为原创几何占位图。图片中的 YOUR APP 文字不会自动改变，需要替换图片。
